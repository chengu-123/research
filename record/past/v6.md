# ArtRASA-v6 最终方案

**全名**：BMCSA-guided Single-Canonical RASA + State-Consistent SLAT Donor Canonicalization + Contact-Anchored Wan2.2 W-RFSDS  
**目标**：从单张闭态图生成 URDF-ready articulated 3D asset。  
**范围**：第一版限制为 single-DoF prismatic / revolute；多关节树结构放入 future work。  
**核心原则**：冻结 TRELLIS、Wan2.2、DINOv2；只优化新增 adapter / head / support gate / texture adapter。

---

## 0. One-line Thesis

给定单张闭态图 `I0`，先用 frozen Wan2.2 I2V-A14B 生成 K 个 fixed-camera pseudo-state frames；再用旧 StageB/BMCSA 作为 no-grad topology prior generator，提取内部 voxel 支持、soft topology、粗关节初值与可选 phantom-KV slots。最终 RFSDS 优化阶段只维护一个 canonical articulated asset：一个 static base、一个 movable part、一个 single-DoF joint。所有 K 个状态由

\[
O_k = B \cup T(q_k)M
\]

确定性派生，因此 base bit-identical by construction。SLAT 阶段采用 state-consistent donor sampling：每个 donor 在对应 state-k geometry 与 image condition `Ik` 下运行，再通过 rigid inverse-warp / feature lookup 融合成一个 canonical SLAT。Wan2.2 W-RFSDS 通过可导 Gaussian rendering 反传到 SS-RASA、PartHead、JointHead、support gate、SLAT-RASA 与 texture adapter。最终导出 base mesh、move mesh、joint.json 与 URDF。

## 1. 研究目标与不可变约束

### 1.1 输入

- 单张闭态图像：`I0`
- Locked-camera articulation prompt，例如：
  - `A locked-off single-camera video. The first frame is exactly the provided image. Only the drawer slides open. The object body remains stationary.`
- Joint type prior：
  - MVP：由 prompt / 用户指定 `prismatic` 或 `revolute`
  - 论文版：两个 branch 同时优化并 model selection

### 1.2 输出

```text
canonical_base.glb
canonical_move.glb
joint.json
object.urdf
optimized_video.mp4
texture_provenance.json
diagnostics/
```

### 1.3 不可变约束

1. **TRELLIS 原始权重冻结**：SS-DiT、SS decoder、SLAT-DiT、SLAT decoders 全冻结。
2. **Wan2.2 原始权重冻结**：Wan VAE 与 Wan DiT 均冻结。
3. **DINOv2 / image encoder 冻结**。
4. **只优化新增模块**：SS-RASA、PartHead、JointHead、support gate、可选 phantom-KV external adapter、SLAT-RASA、texture/color adapter。
5. **最终几何只有一套 canonical base + move**，不是 K 套 state-specific geometry。
6. **K 个 Wan frames 是 pseudo-state conditions，不是真实 multi-state observations**。
7. **base 一致性不是 loss 学出来的，而是由 canonical representation + deterministic warp 保证**。
8. **RFSDS 不是 segmentation teacher**，而是 frozen video prior；它通过 rendered video residual 向可导 3D/4D 表示传梯度。

## 2. 借鉴论文与系统的思想

### 2.1 TRELLIS

**借鉴内容**：TRELLIS 的 SS→SLAT 两阶段、SLAT 的 sparse voxel local latent、以及 mesh / 3D Gaussian / radiance field 多解码器。TRELLIS 的 local manipulation / asset variants 说明其内部 latent 具备空间局部可编辑性。

**用于本方案**：

- SS 阶段用于 canonical geometry、support、base/move evidence。
- SLAT 阶段用于 canonical appearance、exposed texture、local detail。
- local manipulation 启发 region-gated residual 与 base-preserving merge，但不直接等价于 articulated part segmentation。

**不可过度声称**：不能说 TRELLIS 已经显式知道 articulated parts；只能说其内部存在可局部编辑、可区域保持的 structured latent features。

### 2.2 Wan2.2 I2V-A14B

**借鉴内容**：Wan2.2 I2V-A14B 是 image-to-video MoE video model。它的 high-noise expert 更偏 layout / large motion，low-noise expert 更偏 detail / texture。

**用于本方案**：

1. 生成 K 个 pseudo-state condition frames。
2. 作为 W-RFSDS frozen teacher。
3. high/mid noise 用于 geometry + trajectory，low noise 用于 SLAT texture + detail。

### 2.3 CHORD / RFSDS

**借鉴内容**：CHORD 使用 rectified-flow video model 的 velocity residual 优化 4D dynamic representation。

\[
\nabla_\theta L_{\text{W-RFSDS}}
=
\mathbb{E}_{\tau,\epsilon}
\left[
\left(\hat v(z_\tau;\tau,y)-\epsilon+z\right)
\frac{\partial z}{\partial \theta}
\right]
\]

\[
z_\tau=(1-\tau)z+\tau\epsilon.
\]

**用于本方案**：`z` 是 rendered articulated video 经 Wan VAE encode 后的 latent；\(\theta\) 是新增层参数、part logits、joint variables、support gate、SLAT/texture residual。

**实现要求**：

- `wan_vae.encode(V_render)` 不能放进 `torch.no_grad()`，否则梯度回不到 render / 3D variables。
- `wan_dit(...)` 可以 no-grad，因为它只提供 frozen velocity residual。

### 2.4 FreeArt3D

**借鉴内容**：training-free per-instance articulated optimization；把 static 3D diffusion prior 作为 shape prior；使用 base / movable part / joint parameters 表示 articulated object。

**区别**：FreeArt3D 需要 few images in different articulation states。本方案只有单张闭态图；K 状态来自 Wan2.2 pseudo frames，不是真实观测。FreeArt3D 不包含 TRELLIS 内部 in-loop adapter，也不通过 Wan2.2 video prior 优化新增层。

### 2.5 MorphAny3D

**借鉴内容**：MorphAny3D 的关键不是 2D texture back-projection，而是在 SLAT-DiT attention 内部做 latent-space fusion。

- MCA：source/target 分别 cross-attend 后再融合。
- TFSA：用前序帧 self-attn K/V 增强 temporal consistency。

**用于本方案**：从 two-endpoint morphing 扩展为 K-state articulated donor fusion。主线使用 state-consistent SLAT donor sampling：`cond=Ik`，`coords=state-k geometry`，之后通过 inverse rigid warp / lookup 融合成 one canonical SLAT。

**不可过度声称**：不能说 MorphAny3D 已经证明 articulated K-state texture fusion；只能说借鉴 MCA/TFSA 机制，并通过 ablation 证明其在 articulated donor fusion 中有效。

### 2.6 NANO3D

**借鉴内容**：region-aware Voxel-Merge / Slat-Merge 的思想，即 edited region 允许变化，unedited region 显式保持。

**用于本方案**：启发 base-preserving region gate 与 soft-to-hard tying。

**不作为主贡献**：本方案不靠 NANO3D 式 post-hoc merge 修复 K 次采样；base 一致性由 single-canonical + deterministic warp 保证。

### 2.7 PARIS / Articulated Reconstruction

**借鉴内容**：joint axis / pivot 需要物理约束。直接 3D vector axis regression 容易局部最优，S² discretization + residual refinement 更稳定。

**用于本方案**：JointHead 使用 S² bin classification + residual refine；加入 base-move contact-anchor loss，防止 revolute axis 漂在空中。

### 2.8 FlexiCubes

**借鉴内容**：FlexiCubes 适合 gradient-based mesh optimization。

**本方案策略**：训练阶段优先用 TRELLIS Gaussian decoder / differentiable Gaussian rendering；导出阶段用 FlexiCubes mesh decoder 生成 URDF mesh。

## 3. 核心裁决

### 3.1 旧 StageB 的最终定位

旧 StageB/BMCSA 的价值：

```text
K pseudo-state frames
→ K-batched SS-DiT / SCAR / BMCSA / SDEdit
→ open-state interior / cavity / drawer-side evidence 注入 s0 或 shared field
→ s0 即使是闭态，也可能出现内部 voxel
```

旧 StageB/BMCSA 的根本问题：

```text
K 个状态独立生成 z_s^k
→ SS decoder logits 有微小差异
→ threshold / argwhere 放大成 voxel-level topology jitter
→ base 不可能 bit-identical
```

因此：

```text
旧 StageB/BMCSA:
  只做 no-grad topology prior generator

新 ArtRASA:
  per-iter 只优化一个 canonical asset
  K states = B ∪ T(q_k)M
```

### 3.2 为什么需要 BMCSA-derived support？

如果 canonical support 只来自 `I0` 闭态图，TRELLIS 很可能重建出偏小、内部实心、缺少 drawer/cabinet interior 的结构。BMCSA/open states 可提供 drawer side、drawer interior、cabinet cavity、base interior。因此 support 来源必须扩展到：

```text
BMCSA s0
open-state union
inverse-warped move support
motion sweep
dilation
top-K uncertain
```

### 3.3 为什么最终仍是 single canonical？

最终 asset 应是：

```text
one base
one move
one joint
one texture set
```

而不是 K 套 geometry / texture。K 个状态只是同一个 canonical asset 在不同 \(q_k\) 下的 rollout。

### 3.4 Phantom-KV 是否进入主线？

建议：

- 主线可默认启用 phantom-KV slots，但必须有 no-phantom ablation。
- 若实现复杂或初步收益不明显，可降级为 ablation。
- 必须明确：现有 `dit_hidden.pt` 是 block output，不是 self-attn K/V。
- 真正 phantom-KV 需要 `MultiHeadAttention.forward(return_kv=True)` 或在 `to_qkv` 后截取 K/V。

```text

Phase 0:

  Build Interior-Aware SUPPORT_COORDS
  → BMCSA_s0

Phase 3:
  Phantom-KV slot distillation (optional but recommended)

  → low-rank N=32 slots per block/timestep

Phase 4:
  Per-iteration single canonical SS-RASA optimization
  → one canonical occupancy v*
```

## 8. Phase 3：Phantom-KV Slot Distillation

### 8.1 目的

BMCSA 的 continuous K/V 特征中包含跨状态结构证据；相比 K hard voxel 输出，它不会经历 `argwhere / threshold` 放大 jitter。

### 8.2 正确 K/V capture

现有 `capture_dit_hidden_states` 抓的是 block output，不是 K/V。若启用 phantom-KV，需：

```python
MultiHeadAttention.forward(..., return_kv=True)
```

或在 `to_qkv` 后截取并 split。

推荐修改 forward 增加 `return_kv` 参数。

### 8.3 Slot 蒸馏

\[
S_{b,t}=\operatorname{CrossAttn}(Q_{slot}, K/V_{BMCSA,b,t}).
\]

默认：

```text
blocks = {16, 19, 22}
steps = all Euler steps or selected high/mid steps
N_slots = 32
slot frozen after distillation
```

### 8.4 注入方式

```python
h = frozen_trellis_block(h, t, cond)

if block in RASA_BLOCKS:
    delta_dino = KCondCrossAttention(h, cond_K)
    delta_phantom = ExternalKVAdapter(h, slot_KV[block, step], t_emb)

    gate = p_move_16 + p_uncertain_16
    alpha = alpha_max * (t / t_max)

    h = h + alpha * gate * (delta_dino + delta_phantom)
```

原则：

```text
base gate = 0 或强抑制
move / uncertain 可读 phantom evidence
alpha zero-init
alpha(t) 高噪强、低噪弱
```

## 9. Phase 4：Single Canonical SS-RASA Optimization

### 9.1 每 iter 跑一次 canonical SS-DiT

必须明确：

```text
不是 iter 0 cache 后只训 heads。
每个 optimization iteration 都跑一次 SS-DiT canonical forward。
```

TRELLIS 原权重冻结，但计算图保留到 RASA 与 heads。

### 9.2 SS-RASA 输入

```text
canonical noise / latent
primary condition: I0 identity anchor or informative canonical prior
cond_K: K pseudo frames
state/joint code: 只进入 RASA，不进入 frozen TRELLIS 原分支
phantom slots: optional structural prior
```

### 9.3 RASA-Core 结构

```text
same-voxel cross-condition attention
part-slot bottleneck: base / move / uncertain / interior
K-frame confidence gate
region-gated residual
zero-init scale
```

### 9.4 Dual PartHead

```text
16³ semantic branch:
  multi-tap SS-DiT features -> MLP

64³ boundary branch:
  SS-VAE decoder intermediate features -> ConvHead

fusion:
  logits64 = upsample(logits16) + gamma * boundary64
```

输出：

```text
m_base
m_move
m_uncertain
m_interior optional
```

### 9.5 JointHead

输入：

```text
move-mask pooled RASA features

```

输出：

```text

axis: S² bin + residual
pivot/origin: revolute
```

## 10. Phase 5：Deterministic K-State Geometry

### 10.1 Canonical decomposition

\[
B=v^*\cdot m_{base}
\]

\[
M=v^*\cdot m_{move}
\]

### 10.2 K-state rollout

\[
O_k=B\cup T(q_k)M.
\]

Soft training：

\[
P_k(x)=1-(1-P_B(x))(1-P_M(T_k^{-1}x)).
\]

Hard export：

```python
B_hard = (v_star > tau_occ) & (m_base > tau_base)
M_hard = (v_star > tau_occ) & (m_move > tau_move)

for k:
    O_k = B_hard | transform(M_hard, T_k)
```

### 10.3 优点

```text
base bit-identical by construction
move only changes via single-DoF transform
无 K independent argwhere jitter
```

## 11. Phase 6：State-Consistent SLAT Donor Canonicalization

### 11.1 为什么不用 canonical coords + Ik cond

如果：

```text
cond = I_k
coords = canonical coords
```

则 image condition 描述的是 state-k 几何，而 coords 描述 canonical/rest 几何。这是 condition-coordinate mismatch，属于 OOD 风险。

### 11.2 Option A 主线

对每个状态：

```python
coords_k = coords(B | transform(M, T_k))
s_k = SLAT_DiT(noise, cond=I_k, coords=coords_k)
```

这样：

```text
cond = I_k
coords = state-k geometry
```

更符合 TRELLIS SLAT-DiT 训练分布。

### 11.3 Canonicalization

#### Base

base 坐标跨 K 相同：

\[
s_B^*(p)=\sum_k w^B_{k,p}s_k(p).
\]

#### Move

canonical move voxel \(p\) 在 state k 位置：

\[
p_k=T_k(p).
\]

lookup donor feature：

\[
\tilde s_k(p)=\operatorname{Lookup}(s_k,p_k).
\]

融合：

\[
s_M^*(p)=\sum_k w^M_{k,p}\tilde s_k(p).
\]

### 11.4 实现 lookup

对于 sparse SLAT：

```text
scatter sparse features to dense 64³ feature grid
grid_sample / nearest-trilinear lookup
gather back to canonical sparse coords
```

PyTorch `grid_sample` 对 feature 与 query coordinate 可导。

## 12. SLAT-RASA：K-way MCA / TFSA

### 12.1 K-way MCA

\[
h^{MCA}_{i}=\sum_k w_{i,k}\operatorname{CrossAttn}(Q=h_i,K/V=cond(I_k)).
\]

### 12.2 K-way TFSA

\[
h^{TFSA}_{i}=\sum_k \tilde w_{i,k}\operatorname{SelfAttn}(Q=h_i,K/V=cache_k).
\]

### 12.3 donor weights

\[
w_{i,k}=\operatorname{softmax}_k(
\lambda_v visibility_{i,k}
+\lambda_p part\_compat_{i,k}
+\lambda_c frame\_confidence_k
+\lambda_t temporal\_proximity_{i,k}
+\lambda_r RFSDS\_reliability_k
).
\]

### 12.4 区域策略

```text
base exterior:
  prefer I0 / consistent donors

base interior:
  prefer open states where interior visible

move exterior:
  prefer visible state donors

move newly exposed interior:
  prefer late open states

uncertain:
  lower donor confidence, rely more on TRELLIS prior
```

## 13. Rendering 与 RFSDS

### 13.1 训练阶段

使用：

```text
TRELLIS Gaussian decoder
Differentiable Gaussian renderer
```

理由：

```text
smooth gradient
avoids mesh topology jumps
closer to CHORD's 3D-GS optimization philosophy
```

### 13.2 导出阶段

使用：

```text
FlexiCubes mesh decoder
texture baking
URDF writing
```

### 13.3 W-RFSDS 伪代码

```python
V = render_gaussian_video(B, M, q_k, texture)

z = wan_vae.encode(V)  # grad ON wrt V

eps = torch.randn_like(z)
tau = sample_tau(iter)
z_tau = (1 - tau) * z.detach() + tau * eps

with torch.no_grad():
    v_hat = wan_dit(z_tau, tau, image=I0, text=locked_prompt)

grad = v_hat - eps + z.detach()
loss = (z * grad.detach()).sum()
loss.backward()
```

### 13.4 梯度流向

```text
Wan latent z
← rendered video
← Gaussian renderer
← Gaussian / SLAT features
← state geometry B ∪ T(q_k)M
← part logits
← joint params
← SS-RASA / SLAT-RASA / heads
```

## 14. Contact-Anchored Joint Prior

### 14.1 动机

Wan2.2 可以让视频看起来像“开门/开抽屉”，但不保证 joint 物理合理。为了输出 URDF-ready asset，必须约束：

```text
base 和 move 应接触
base-move 边界应连通或近连通
revolute axis 应穿过 contact anchor set 附近
prismatic direction 应与滑动/接触结构一致
```

### 14.2 Soft contact field

\[
P_B(x)=P_{occ}(x)P_{base}(x)
\]

\[
P_M(x)=P_{occ}(x)P_{move}(x)
\]

\[
C(x)=\exp\left(-\frac{d_B(x)^2+d_M(x)^2}{\sigma_c^2}\right).
\]

### 14.3 Contact mass

\[
L_{contact-mass}=\max(0,\tau_m-\sum_x C(x))^2.
\]

### 14.4 Anchor refresh

每 N iter：

```python
with torch.no_grad():
    A = topM(C)
    A = largest_connected_component(A)
    anchors = farthest_point_sample(A, M_anchor)
```

### 14.5 Revolute axis-anchor

轴线：

\[
\mathcal{L}(o,a)=\{o+\lambda a\}.
\]

点到线距离：

\[
d_{line}(p;o,a)=\|(p-o)\times a\|_2.
\]

loss：

\[
L_{axis-anchor}=\operatorname{softmin}_{p\in A}d_{line}(p;o,a)^2.
\]

pivot-near：

\[
L_{pivot-near}=\min_{p\in A}\|o-p\|^2.
\]

axis-direction：

\[
L_{axis-dir}=1-(a^\top u_1)^2,
\]

其中 \(u_1\) 是 contact anchor strip 的 PCA 主方向。

### 14.6 Prismatic prior

\[
L_{pris-dir}=1-(a^\top \hat d_{motion})^2.
\]

collision loss：

\[
L_{collision}=\sum_{k,x}P_B(x)P_M(T_k^{-1}x).
\]

### 14.7 Schedule

```text
iter 0-600:
  no contact loss

iter 600-1000:
  contact_mass + collision, weak λ=0.1

iter 1000-1500:
  axis_anchor + pivot_near + axis_dir

iter 1500-2000:
  anchor fixed or low-frequency refresh
```

## 15. 总损失

\[
L =
L_{W-RFSDS}
+\lambda_0 L_{first}
+\lambda_1 L_{part}

## 18. 贡献点

### C1. BMCSA-guided interior-aware canonical support

旧 StageB/BMCSA 能发现 hidden topology，但 K hard voxel outputs 有 jitter。我们只保留其 soft topology evidence，构造 interior-aware canonical support，丢弃 K hard geometry。

### C2. Single-canonical SS-RASA with dual evidence injection

每 iter 只优化一个 canonical SS。RASA 同时接收：

```text
K-frame DINO conditions: appearance evidence
BMCSA support / optional phantom-KV: 3D structural evidence
```

K states 由 \(B \cup T(q_k)M\) 确定性派生，base bit-identical by construction。

### C3. State-consistent SLAT donor canonicalization

每个 SLAT donor 在对应 state-k coords 和 image condition 下生成，避免 `canonical coords + Ik cond` 的 OOD mismatch。再通过 rigid inverse-warp / lookup 融合成 one canonical SLAT。

### C4. Contact-anchored single-DoF joint optimization

通过 base-move contact field、anchor set、axis-through-anchor、pivot-near、collision loss 防止 axis/pivot 漂浮，使输出 joint 物理可信、URDF-ready。

### C5. Wan2.2 W-RFSDS for inserted-module optimization

冻结 Wan2.2 与 TRELLIS，用 W-RFSDS 优化新增层、分割、轨迹和纹理。Wan2.2 不作为 segmentation teacher，而作为 fixed-camera video prior。

## 21. Safe Claims / Unsafe Claims

### 21.1 Safe claims

```text
We use Wan2.2-generated frames as pseudo-state conditions, not observations.
We freeze TRELLIS and Wan2.2 and optimize inserted modules only.
We use old BMCSA outputs only as topology priors, not final geometry.
We avoid differentiating through argwhere by using fixed support + differentiable gate.
We derive all K states from one canonical base/move representation.
We use contact-anchor priors to constrain joint axes near base–move boundaries.
```

### 21.2 Unsafe claims

```text
TRELLIS already knows articulated parts.
Wan2.2 provides segmentation labels.
K Wan frames are real multi-state observations.
argwhere is differentiable.
MorphAny3D proves articulated K-state texture fusion.
We recover true hidden interior geometry.
We solve arbitrary multi-joint object articulation.
```

## 22. 最终一句话

ArtRASA-v6 用 Wan2.2 生成 K 个 pseudo-state conditions，用旧 StageB/BMCSA no-grad 预提取 interior-aware topology prior 与可选 phantom-KV slots；RFSDS 优化阶段只维护一个 canonical base/move/joint 表示，通过 SS-RASA、PartHead、JointHead 和 support gate 得到 \(B,M,T(q_k)\)，所有状态由 \(B \cup T(q_k)M\) 确定性派生；SLAT 阶段在 state-consistent coords 下生成 donor features，再 inverse-warp 融合成 one canonical SLAT；Wan2.2 W-RFSDS 反传优化新增层、分割、轨迹和纹理；contact-anchor loss 保证 joint 物理落在 base-move 接触边界附近。
