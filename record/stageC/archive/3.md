Q1: 是否补全 base/move 的 canonical？
Yes，必须要。但是要分清两种 "completion"——你的纸笔创新只发生在其中一种。

两种 "completion" 区分
类型	操作	解决什么问题	谁的活
Geometric completion	Canonical 帧下跨 state 取并集（对 base 直接并集；对 move_p 先逆变换再并集）	state k 里被遮挡的部分，state k' 能看见 → 通过跨 state 汇总恢复	Stage C（必须）
Texture completion	每个 canonical voxel 从可见它的 state 的图像里借像素/feature，做 cross-state inpaint/blend	纯 3D 占据没有材质/颜色；要从多 state 图像补全	Stage D（你的创新）
你的论文创新是 Texture completion via MorphAny3D 风格的 cross-state 语义 inpaint，这是 Stage D。Stage C 必须 geometric completion 正确，否则 Stage D 的 texture 工作建在错误几何上。

Q2: 多 joint = 分别找 move 的 canonical？
Yes, 核心上是。但是"分别"不是"独立" —— 需要 joint segmentation 做对。

多 joint 的结构
对 P 个 moving parts 的铰接物体：

1 个 base
P 个 moving parts，每个有自己的 joint (axis + type) 连到 base（假设所有 joint 都是 base 的直接子节点，即 kinematic tree 是星型）
如果 joint 是嵌套的（part2 是 part1 的子节点），是 kinematic chain，复杂，AAAI 版本先不上
为什么不能 "完全独立"
如果你对每个 move_p 单独跑 EM，会遇到：

Part 混淆：一个 voxel 可能被两个 part 都竞争。必须全局软/硬 assignment。
Axis 冲突：两个 part 的 axis 可能重叠或矛盾。BIC 对单个 part 做 revolute-vs-prismatic OK，但不能决定 "这是 1 个 part 还是 2 个 part"。
Kinematic consistency：如果 part_1 和 part_2 的 transform 对同一 state k 矛盾（比如 state 3 里 part_1 开了但 part_2 还关着），要求 per-state per-part 独立 transform。这是合理的假设（反正我们每个 state 都 fit 独立 params），但全局一致性要检查。
正确的多 joint 做法
扩展的结构化 EM（上次讨论框架的自然推广）：

Variable:
  A(v) ∈ {base, move_1, ..., move_P, outlier}   // 多标签 per-voxel (soft or via α-expansion)
  T_k^(p) for each (k, p)                        // per-state per-part rigid transform
  axis_p, type_p for each p                      // per-part joint parametrization
Constraints:
  - 每个 part 的 canonical volume 连通（graph cut 自然保证）
  - 每个 part 的 axis 与其 contact_p 几何相容
  - Cross-state 语义先验 (Stage B M_attn) 只区分 base vs "非 base"
    但**不直接**区分 move_1 vs move_2（M_attn 是 base vs move 的单值 mask）
Part index 初始化:
  - 对 M_attn 低 (< 0.5) 的 voxel，做 connected component → 每个大 CC 一个 part_id
  - 小 CC 合并到最近的大 CC 或 outlier
  - K 个 states 中 move voxel 的 connected component pattern 相似性 → 同一 part
关键洞察：part 数 P 由跨 state trajectory 自动确定
