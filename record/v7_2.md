## 1. 执行摘要：一句话最终决策

**RASA 最终方案 = "单环优化 + W-RFSDS τ 加权采样 + RASA 速度修正适配器（仅插在 SS-DiT 内，SLAT-DiT 仅做 LoRA 微调）+ 5 项 loss 上限 + GIM-DKM 风格的 axis 冷启动 + 800 步纯几何热身 + K=2 状态硬合成 noisy-OR 仅在监督端"。一线 vs 两线的最终裁定为"**形式一线，机制两线**"——即用一个优化循环、一组共享变量，但通过 τ 阶段化与参数组冻结切换，在工程上等价于 CHORD 的 coarse→fine 退火，避免 ProlificDreamer/DreamGaussian 已记录的"texture 早收敛吃掉 geometry 梯度"失败模式。

## 3. RASA 最终设计（最简形式）

**前向通路**（已基于 TRELLIS 真实文件结构落地）：

输入单张闭态图 → DINOv2 编码（TRELLIS 原管线，冻结）→ **SS-DiT** 12 步 Euler 积分（rectified flow 速度场 v_θ；每块 `ModulatedTransformerCrossBlock` = AdaLN(t,cond) + SelfAttn(4096 voxel tokens) + CrossAttn(image tokens) + FFN）[V-CONFIG: `ss_flow_img_dit_L_16l8_fp16`，16³×8 latent] → 解码 64³×1 occupancy → `argwhere(occ>τ)` 稀疏化（**这就是用户提到的"argwhere 瓶颈"，是稠密→稀疏的硬阈值点**）→ **SLAT-DiT** 12 步 Euler（patch=2 over 64³，Swin window=8 sparse attention）→ 三个独立 decoder（GS / RF / mesh）。

**RASA 注入点**（仅这两处可学习）：

1. **SS-DiT 速度修正分支**：在 SS-DiT 的每个 `ModulatedTransformerCrossBlock` 之间，加并联零初始化 `g_φ(h_t, t, M, A, O, θ_k)`，输出 ε 量级残差，与原始 v_θ 相加：`v_corr = v_θ + α(t) · g_φ`，其中 α(t) 是可学时间门，g_φ 接收当前 movable mask logits M、关节轴 A、原点 O、当前态 θ_k 作为 cross-attention 的额外 KV。**[MECH]** 此操作不破坏 rectified flow ODE，因为 ODE 仅要求确定性向量场；扰动场仍为合法 ODE。
2. **SLAT-DiT QKV-LoRA**（rank=8）：仅低秩，仅 attention，不改 AdaLN，不改 FFN。仅在两线机制的 Line B（纹理）激活。

**显式结构变量**（直接可学）：
- 关节类型 logits（type ∈ {revolute, prismatic}，2 维 softmax + Gumbel-Straight-Through）
- 关节轴 A ∈ S² （Rodrigues 参数化的 2 维，避免单位球退化）
- 关节原点 O ∈ ℝ³
- 关节范围 [θ_min, θ_max]
- K=2 的状态标量 θ_1=0（闭态）, θ_2 自由
- movable mask logits M ∈ ℝ^{N_active}（在 SLAT 的稀疏 voxel 上而非密集 64³）
- SLAT 残差 Δz_slat（rank-限制）

**输出形式**：单 canonical base mesh + 单 canonical movable mesh + (type, A, O, range, θ_k=2)。K-state 仅用于 Wan2.2 监督端的 noisy-OR 合成，不作为最终交付。

## 4. Loss 最终清单（≤5 项）+ 同行实证基线

### 同行实证基线（代码级）

| 工作 | 优化端 loss 数 | 蒸馏类型 | 结构性约束 |
|---|---|---|---|
| FreeArt3D | **2**（L_SDS_3D + L_vox） [V-PAPER] | 3D-RF-SDS（用 TRELLIS 当 prior） | 双 hash-grid + max-occupancy |
| CHORD | **3**（L_W-RFSDS + L_temp + L_ARAP） [V-PAPER] | W-RFSDS over Wan2.2 | 双层级 control points + Fenwick 累积 |
| DreamGaussian (image branch) | **4**（10000·L_rgb_ref + 1000·L_mask_ref + λ_sd·SDS + λ_zero123·SDS_zero123） [V-CODE] | 2D-SDS + Zero123 | 仅 GS densify_and_prune |
| ProlificDreamer Stage-2 | **3**（VSD + λ_normal=5000 + λ_entropy=10） [V-PAPER] | VSD | DMTet |
| PARIS | 4（L_rgb 双态 + L_mask + L_blend + L_motion-reg） [V-PAPER] | 无（光度自监督） | 双 NeRF + 反向 motion field |

**裁定**：FreeArt3D 用 2 项 loss 拿下 SIGGRAPH Asia 2025 是当前最 ruthless 基线；RASA 采用 ≤5 项的"FreeArt3D + CHORD"混合形态。

### RASA 最终 5 项（按必要性分类）

**By-construction（不是 loss，是结构约束，不计入计数）**：
- 单 canonical base + 单 canonical movable：参数共享天然完成 part decomposition——不需要 PARIS 的 L_blend [MECH]。
- 硬合成 W(θ_k)·Occ_part ⊕ Occ_base 通过 max（noisy-OR 的连续松弛）：不需要显式 mutual-exclusivity loss [MECH，参照 FreeArt3D §3.2]。
- Rodrigues SE(3) + θ_k 标量：自动满足关节闭式约束，不需要 motion-reg loss [MECH]。

**Essential（5 项上限内）**：

1. **L_W-RFSDS**（核心蒸馏，~95% 总权重）：基于 Wan2.2 I2V-A14B，τ ~ ŵ(τ) = w(τ)/∫w（CHORD Eq.4），ε 通过差分渲染 K=2 个 noisy-OR 合成态投影到视频帧；t ≥ boundary=0.900 路由到 high-noise expert，t < 0.900 路由到 low-noise expert（**硬开关，无 soft mixture** [V-CODE: Wan2.2 config boundary=0.900 (I2V)]）。
2. **L_vox**（FreeArt3D 风格 voxel L2 锚定，权重 ~0.1）：composed occupancy vs TRELLIS 单次裸推理的参考 occupancy，防止漂移，是 FreeArt3D 消融行 (b) 已实证必需的稳定项。
3. **L_ref_img**（输入闭态图的 RGB MSE，权重 ~10–100，仅闭态视图，仅 θ_1=0）：DreamGaussian 把这一项权重设为 10000（[V-CODE: main.py L_rgb_ref]），但 DreamGaussian 没有 voxel anchor，所以权重大；RASA 因有 L_vox，可降到 ~10。这是单图监督的最强信号，不可省。
4. **L_mask_consistency**（θ_1=0 时输入图 SAM mask 与渲染 silhouette 的 BCE，权重 ~1）：是诱导 movable mask logits M 与图像分割对齐的 anchor。DreamGaussian 用 1000 权重；RASA 因 SAM mask 仅作 weak prior（不当 GT）取 1。
5. **L_axis_init_anchor**（关节轴与 GIM-DKM 启发的初值之间的余弦距离正则，权重 ~0.5，仅前 500 步线性衰减到 0）：解决 axis 死区问题。FreeArt3D 通过 GIM-DKM 完成同等功能（[V-PAPER FreeArt3D README confirms `gim/weights`]）。

**Cut（明确剔除）**：
- ❌ L_ARAP（CHORD 专属，仅在 control-point deformation 参数化下成立；RASA 是刚性关节，不需要） 
- ❌ L_temp 3D-flow（CHORD 专属，4D 场景使用，RASA 是静态结构 + 标量 θ_k） 
- ❌ λ_normal 法线 SDS（ProlificDreamer Stage-2 专属，依赖 DMTet；RASA 用 SLAT decoder） 
- ❌ λ_entropy 不透明熵（ProlificDreamer 专属；TRELLIS 已通过 VAE 解码器规约 occupancy） 
- ❌ L_blend 部件互斥（PARIS 专属；RASA 由参数共享 by-construction） 
- ❌ orient loss（threestudio 专属；TRELLIS 解码器内含法线一致性）

## 5. 一线 vs 两线最终裁定

### 代码级证据汇总

**Wan2.2 MoE 的 τ 路由是否提供"几何/纹理"天然解耦？**

[V-PAPER] Wan2.2 README 与 HF 模型卡原文：**"high-noise expert ... overall layout; ... low-noise expert ... refining video details."** [V-CODE] boundary 是 deterministic if/else 硬阈值（I2V=0.900，T2V=0.875），无 soft gate，无 learned router。这是**"基础设施已具备"**。

**但是有四个具体的反对证据**：

1. [V-PAPER] **CHORD 是已知唯一在 Wan2.2 上做 SDS-类蒸馏的工作**（项目页 yanzhelyu.github.io/chord 已确认使用 Wan 2.2 14B I2V），它**主动选择了顺序退火 coarse→fine**，而非同循环 τ-routing。原文："we only optimize the coarse level of control points at earlier iterations when τ is large, and we introduce the fine control points later, once τ becomes smaller"——这是**已发表的、在同一 backbone 上的、工程实证**反对一线 τ-routing。
2. [V-PAPER] **Wan2.2 在 boundary=0.900 之上的训练样本占比 < 6%**（issue #15 中开发者承认默认 logit-normal 不重新加权时的训练分布），这意味着 sampling t ∈ [0.900, 1.0] 处 high-noise expert 的训练密度不均匀，梯度方向在边界附近**未必被 fine-tuned 校准**。这是 raw τ-routing 的隐藏陷阱。
3. [V-PAPER] **"texture 吃掉 geometry 梯度"是文献内反复记录的失败模式**——DreamFusion (Janus 65.6%)、DreamGaussian（UV-SDS blocky → 改用 MSE）、Magic3D（必须 coarse-to-fine）、Fantasia3D（显式 disentangle）、TextureDreamer（必须 ControlNet-normal 解纠缠）。**所有成功的工作都用顺序/阶段化解决，没有一个用同循环 τ-routing**。
4. [V-CODE TRELLIS] SS-DiT 与 SLAT-DiT 是**两个独立的 DiT**，不是一个；SS 阶段产 16³×8 latent → 64³ occupancy，SLAT 阶段产 sparse appearance latent。几何与纹理已经在 TRELLIS 内部架构上分离——这意味着**最自然的解耦轴是 SS-vs-SLAT 阶段，而不是 Wan2.2 内部的 τ 边界**。

### 最终裁定

**形式上一线，机制上两段**：

- **一个优化循环**（用户的"一线最理想"诉求），单组共享变量（M, A, O, type, θ_k, RASA-φ, SLAT-LoRA），单个 outer step。
- **机制上隐式两段**：通过参数组冻结调度实现——
  - **第 1 阶段（iter 0–800，"几何阶段"）**：仅激活 SS-DiT 的 RASA-φ + 显式结构变量（M, A, O, type, θ_k）；冻结 SLAT-LoRA。τ 仅从 [0.900, 1.0]∩ŵ(τ) 采样，强制路由到 Wan2.2 high-noise expert，监督几何/布局/运动。Loss 启用：L_W-RFSDS, L_vox, L_ref_img(权重 10), L_mask_consistency, L_axis_init_anchor（前 500 步）。
  - **第 2 阶段（iter 800–1500，"过渡阶段"）**：解冻 SLAT-LoRA；τ 从 ŵ(τ) 全域采样（自然两专家都激活）；几何参数学习率降到 1/3。
  - **第 3 阶段（iter 1500–2000，"纹理阶段"）**：冻结 RASA-φ + 结构变量；仅 SLAT-LoRA + Δz_slat 可学；τ 限制在 [0.05, 0.85]，强制 low-noise expert 主导；L_axis_init_anchor 关闭。

**为什么这等价于"一线"而非"两线"**：因为是同一个 PyTorch optimizer，同一个 loss tensor，同一组 backward hooks；只是**learning rate schedule + τ sampling distribution 在 epoch 上分段**。这与 ProlificDreamer 三阶段（必须重新初始化表示）、CHORD 双层 control points（必须新增参数）有本质区别——RASA 不增删任何参数。

[V-PAPER 支持] CHORD 的退火 CDF 调度 h(τ_i)=1−i/(I+1) 是这一形态的精确数学先例。

**[HYP，需消融]** 真正的"同步一线（每步都做 τ-routing 切片到 disjoint 参数组）"作为消融对比：在 §6 反驳点 #1 的 ablation 表里出现。

## 6. RFSDS 梯度方向 sanity test 协议（可执行）

**原假设**：Wan2.2 I2V-A14B 对错误的 (mask, axis, type) 提供正确方向梯度，即 cos(−∇_φ L_RFSDS, φ_GT − φ_wrong) > 0。

### 测试样本构造

从 PartNet-Mobility 各类别（drawer/cabinet door/laptop/microwave/scissors/refrigerator/trashcan）每类抽 20 个实例，共 7×20 = **140 个**。每实例渲染闭态图作为单图输入。GT 几何/关节参数已知。

### 5 维扰动诊断电池

| 维度 | 扰动级别 | 扰动操作 | 测量量 |
|---|---|---|---|
| Mask | 5 级 | erode/dilate movable 区域至 mIoU = {0.95, 0.85, 0.70, 0.50, 0.30} | cos(−∇_M L, M_GT − M_wrong) |
| 轴方向 | 5 级 | 偏角 = {5°, 15°, 30°, 60°, 90°} | cos(−∇_A L, A_GT − A_wrong) |
| 轴原点 | 5 级 | 偏移 = {2%, 5%, 10%, 25%, 50%} 物体对角线 | 同上 |
| 关节类型 | 1 级 | 反转 revolute↔prismatic | sign(L(GT) − L(swapped)) |
| θ_k | 5 级 | 对错 θ_2 加 {±10%, ±25%, ±50%} 偏差 | 同 cos 测度 |

### 通过门槛

- **大梯度方向正确率（GDR）**：在每个扰动级别下 cos > 0 的样本比例。**门槛：在 mIoU≥0.50 / 角度≤60° 时 GDR ≥ 70%**（[HYP] 这是基于 ProlificDreamer/CHORD 隐含报告的 SDS 信噪比设定的合理阈值，需在 RASA 实测后微调）。
- **类型可分性**：sign(L(swap)) 的正确率 ≥ 80%。
- **τ 区间分别测**：在 high-noise τ ∈ [0.90, 1.0] 与 low-noise τ ∈ [0.05, 0.85] 各跑一次。**预期 high-noise 区对 axis/type/mask 更敏感，low-noise 区对 θ_k 细节更敏感**——这是 [HYP] 的强测试，若 high-noise 区在 axis 上的 GDR 低于 low-noise 区，说明 Wan2.2 MoE 的 layout/detail 划分在反向梯度上不严格成立，需回退到 τ 全域采样。
- **统计显著性**：每类 20 例 × 5 级 × 7 类 = 700 测点，bootstrap 95% CI 不跨过 50% 即视为通过。

### 失败回退

若整体 GDR < 50%（即 Wan2.2 提供的方向无效），按优先级：
1. 切换到 SVD（Stable Video Diffusion）或 AnimateDiff 作为 prior 重测（消融对比）。
2. 强制使用 axis/origin 的 GIM-DKM 估计作为硬约束（不再让 RFSDS 优化它们）。
3. 退化到 PAct/MonoArt 风格 feed-forward 监督，需引入 PartNet-Mobility 半监督预训练——但这违反"无 articulated dataset"约束。

## 7. 初始化与"鸡生蛋"循环破解协议

### FreeArt3D 是怎么做的（代码级事实）

[V-PAPER + V-CODE README] FreeArt3D 用 **GIM-DKM**（Geometric Image Matching, Deep Kernelized Matching）—— 一个**静态图像对的稠密对应模型**，**不是光流，不是在生成视频上跑的**。它运行一次产出对应点对 → 提取轴/枢轴的几何先验 → 喂给 SDS 优化。它**不依赖** SAM（README 把 SAM 列为可选用户侧预分割）。它**不依赖**生成视频。FreeArt3D 的 mask 不是显式估计的，而是**两个 hash-grid + max-occupancy**的隐式 part assignment（SDS 梯度自然把"动的体素"挤到 part grid，"不动的"挤到 base grid）。

这给 RASA 三个直接借鉴：
1. axis 冷启动**不需要**先跑 Wan2.2 视频再算光流——这避免了"轴 ← 视频 ← 已有轴"的循环。
2. mask 不需要 iter-0 GT 监督——SAM 只是 weak anchor。
3. 真正的破环在于"参数共享 + 硬合成 by-construction"。

### RASA 初始化方案

| 变量 | iter 0 初值 | 来源 |
|---|---|---|
| Movable mask logits M | 输入图过 SAM2（auto-prompted）的最大移动嫌疑 segment 投影到 SLAT 稀疏 voxel，logit=2.0 内、−2.0 外 | 单次 SAM 推理 |
| 关节轴 A | 用 GroundingDINO + bbox 启发式（panel→水平轴；drawer→bbox 法向；scissors→对角线）+ 物体类别 prior（CLIP 分类） | 一次性脚本 |
| 关节原点 O | bbox 边缘 mid-point | 同上 |
| 关节类型 logits | drawer/door 类先 [0.3, 0.7] 偏 prismatic/revolute；其余 [0.5, 0.5] | CLIP 类别先验 |
| θ_max | revolute → 90°；prismatic → 0.3·bbox 边长 | 启发 |
| θ_2 | 取 0.5·θ_max | 启发 |
| RASA-φ | zero-init（Conv-zero 残差） | ControlNet 标准 |
| SLAT-LoRA | 标准 LoRA init（A=Gaussian, B=0） | LoRA 标准 |

### 三循环依赖如何断

| 鸡生蛋循环 | 破解机制 |
|---|---|
| Mask ↔ axis ↔ motion | **参数共享 + 硬合成 by-construction**（FreeArt3D 路径）：max(Occ_base, W(θ_2)·Occ_part) 强制让 SDS 梯度自然挑出"动 vs 不动"，不需要先验 mask |
| Cross-state coupling ↔ K 态差异 ↔ 关节参数 | **K=2 + θ_1=0 锚定 + θ_2 自由**：θ_2 从 0.5·θ_max 启动即提供**有限但非零**状态差，Wan2.2 在该 θ_2 下生成的 video frame 已足够提供 RFSDS 信号 |
| RFSDS 监督 ↔ rendered video ↔ 关节参数 | **800 步纯几何热身 + L_axis_init_anchor 衰减**：前 500 步 axis 锚到启发初值，期间 RFSDS 仅修正几何形状与 mask；500–800 步逐步解锁 axis；800 步后所有结构变量自由 |

[HYP] 这套破环依赖 SAM/GroundingDINO/CLIP 都不出灾难性错误。在 OOD 类别（如 RASA 强行测的"出分布"如 suitcase）上需要消融"用零初值 vs 启发初值"。

## 9. 失败模式 + 诊断信号

| 失败模式 | 诊断信号（训练时实时监控） | 缓解 |
|---|---|---|
| **Mode collapse**（part grid 学成空，base 吞掉一切） | Occ_part 体积分数 < 5% 持续 200 步 | L_axis_init_anchor 加权；强制 Occ_part L1 下界正则；切回 K=1 退化测试 |

## 结论

RASA 的最终核心决策是"**形式一线、机制两段、速度修正、5 项 loss、SS-DiT 内插适配器、Wan2.2 high-noise expert 主导几何监督、low-noise expert 主导纹理监督，且通过 epoch 上的 τ 调度而非每步 routing 实现解耦**"。这一形态与 v7 速度修正、v7.1 staged_dual_path、Claude loss_claude.md 三方在以下意义上达成融合：保留 v7 的速度修正机制（[V-CODE 可行] 不破坏 RF ODE）、采纳 v7.1 的几何/纹理分阶段时间安排但合并到单 optimizer（[V-PAPER 支持] CHORD 在 Wan 2.2 上的退火证据）、采纳 Claude 的 ≤5 项 loss 极简主义（[V-PAPER 支持] FreeArt3D 用 2 项即达 SIGGRAPH Asia 2025）。token 级 cross-state attention 仅作为 §8 ablation #7 的对照，不进主推方案——理由是它要 monkey-patch self-attn 模块而速度修正是干净的并联零初始化分支。

novelty 评估给出严肃警示：**当前 scope 在 CVPR 2026 主会上仅 4–4.5/10 viability**，原因是 MonoArt（2026.03）已经用同样的 frozen TRELLIS 做了同样的单图关节重建。RASA 的生死取决于两件事——**RASA-φ 适配器位置消融能否拿到 ≥10% 提升**，以及**Wan2.2 sanity test 能否在 7 类 PartNet-Mobility 上 GDR ≥ 70%**。前者证明架构创新，后者证明 prior 有效。任何一项失败都意味着应改投 workshop 或扩展到 multi-joint scaling 后再投主会。

最关键的一项缺失证据：**用户私有仓库 `chengu-123/research` 不可达**，因此 SCAR 究竟是 loss、layer 还是 algorithm，dit_hidden 捕获在哪一块，SDEdit Pass-2 注入点是否与本方案的"τ 三阶段"兼容——这三件事必须由用户直接贴出 `stage_b_scar.py` 才能落最后一锤。在拿到该文件之前，本方案的 §3 RASA 注入位置与 §5 三阶段调度都建立在 TRELLIS 公开代码 + Wan2.2 公开 config 的合理推断之上，标 [V-CODE-TRELLIS]/[V-CONFIG-Wan2.2]/[MECH] 处可信，标 [需用户私下提供源码核对] 的部分需用户自查。
