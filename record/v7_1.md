# RASA 最终方案：以 Option B 适配器、两阶段+τ 内分工、四 loss 主线为核心的 AAAI 投稿设计

## 1. 执行摘要

**核心结论是清晰的**：RASA 应当采用 **token 级 cross-state attention（零初始化残差，写入 SS-DiT 块内）作为唯一耦合机制**，把 v6/v7/v7.1/loss_claude 中所有 velocity correction / x̂₀ warp / 显式 SE(3) renoise 这一支彻底剪掉；优化结构应当是 **两阶段（SS 几何 → SLAT 纹理），但每阶段内部用 τ 区间分工 + 高/低噪声专家路由实现"看起来像一条线"**；loss 项必须从 v7/v7.1/loss_claude 当前的 7+ 项收敛到 **4 项核心 + 至多 2 项 stage-gated 正则**；初始化必须使用 **类别先验 + 学习型 articulation predictor（Particulate 或 ART 风格）级联**，绝不允许随机初始化关节参数；RFSDS sanity test 协议是 AAAI 论文的关键卖点之一，必须在主文（不是附录）报告。

**关于用户最关心的"一条线 vs 两阶段"**：基于 ProlificDreamer / DreamGaussian / Magic3D / Fantasia3D / TextMesh / DreamArt 的代码与论文铁证，**纯单循环联合优化在已发表的 SOTA 中事实上失败**：唯一公认的"单循环"成功例（HiFA、LucidDreamer、GaussianDreamer）要么是因为 3DGS 表示让"几何/纹理在单步内不可分"，要么靠 timestep annealing 模拟相位，且都不涉及 TRELLIS 这种 SS↔SLAT 表示切换。但用户的"一条线理想"可以通过 **τ-routing + Wan2.2 MoE 自然分工** 在工程实现上呈现为单循环（一个外层 for 循环、一组优化器），同时在数学上保留两阶段的归纳偏置。这是本方案的折衷推荐：**外形是一条线，骨子里是两阶段**。

**关于"loss 是否过载"**：基于 13 份代码/论文实证，SDS 类工作的 active-default loss 中位数=3，threestudio 默认 7–8。RASA 当前 v7.1/loss_claude 的 7+ 项 **不属于异常**，但 reviewer 真正在意的是消融充分性而非 loss 数。建议把 loss 重组为"1 个核心监督（W-RFSDS） + 2 个必需锚点（rest-state photometric、part assignment entropy） + 1 个尺度锚（disk）"，把 normal-smooth / sparsity / orient 都做成 stage-gated，这样在任何瞬时 active loss ≤ 4。

**关于 chengu-123/research 仓库**：受沙箱安全策略限制，无法直接抓取该仓库的 raw 文件（URL 不在任何 search/fetch 结果中且无可公开访问镜像）。继承策略基于用户上传的 v6/v7/v7.1/loss_claude 文档描述给出，下文 §5 明确标注此约束。

## 2. v6/v7/v7.1/loss_claude 四份前置方案点对点对比融合

四份方案的核心分歧集中在三个轴：**耦合机制（velocity correction vs token cross-attn）**、**优化拓扑（一条线 vs 两阶段）**、**loss 项数（≤4 vs 7+）**。

**v6** 的特点是结构最丰满但耦合机制偏向 SDEdit 式 x̂₀ warp + renoise，把 K-state 一致性外置在整流流轨迹之外。这与 CHORD/FreeArt3D 的"训练自由、推断时使用"哲学一致，但 v6 试图把它升级为"可学习的 RASA adapter"，**这是范式错位**：rectified flow 的 OT 直线轨迹假设要求 v_θ 是一个干净的速度场参数化，每步在 x̂₀ 上做 SE(3) warp 再 renoise 会把网络从未见过的 off-distribution x_t' 喂回去，RF-Inversion (NeurIPS 2024) 与 OT-RF-Editing (2508.02363) 都明确报告这种 trajectory deviation 累积。v6 应被剪掉。

**v7** 与 **v7.1** 都倾向 velocity correction，区别在于 v7.1 进一步把 correction 模块化为 adapter 形式，并保留了 zero-init 雏形。这是从"轨迹外编辑"向"块内残差"过渡的中间态，**但仍未达到 ControlNet/IP-Adapter 的严格 identity-at-init 标准**：只要 θ_k ≠ 0 时存在显式 W(θ_k) 作用在 x̂₀ 上，初始化时前向就 ≠ vanilla TRELLIS，前 200 步 loss 必然有 spike，pretrained 先验被立即扰动。这条路径上 v7.1 比 v7 更优，但仍不如 Option B。

**loss_claude** 的 token-level cross-state attention 方向是对的——它就是 Option B。它的问题在 loss 设计上：把 K 个 state 之间的所有可能交互（cross-state photo consistency、cross-state SDS、cross-state mask 一致、跨态 SE(3) cycle、几何先验等）都列成显式 loss 项，导致 7–9 项膨胀。loss_claude 需要在架构主张上**直接采纳**，但 loss 项必须按 §4 重新削减。

**融合判定**：架构走 loss_claude 的 token-level cross-attn 路线（Option B）；loss 项数走 v6 的极简哲学（FreeArt3D 风格的 ≤4 项）；优化拓扑借鉴 v7.1 的"一条线表观"但内部实现 §5 描述的两阶段+τ-routing；初始化协议从 v7/v7.1 的 SAM+category 先验中保留 §7 的级联。最终结果是一份在每一根轴上都"取最强项"的合成方案。

## 3. RASA 最终设计（最简形式）

**输入**：单张闭态 RGB 图像 I₀。**冻结模型**：TRELLIS 全栈（SS-DiT + SLAT-DiT + 解码器）+ Wan2.2 I2V-A14B（含两个 expert）。**可学习参数**：(a) RASA adapter 权重 W_adapter（约 50–150M，残差注入 SS-DiT 每隔一层，零初始化输出投影）；(b) 显式结构变量——共享关节参数 (type, axis a∈ℝ³, origin p∈ℝ³, range)、per-state 标量 θ_k、part assignment soft mask；(c) SLAT residual 偏置（用于纹理细化阶段）。

**RASA adapter 内部结构（Option B 终选）**：在 SS-DiT 每个 transformer block 的自注意力之后，插入一个 **Cross-State Attention** 模块。Q 来自 state-k 的 token，K/V 来自所有 K 个状态 token 沿 token 轴 concat 形成的序列。**相对位姿偏置**通过把 W(θ_k − θ_j) 的六维代数（轴角 + 平移）经一个轻 MLP 编码为 attention bias，加到注意力 logits 上（参考 MVDream 的 camera embedding 与 CAT3D 的 Plücker raymap）。**输出投影 W_o 严格零初始化**，残差形式 hidden_k ← hidden_k + W_o · CrossStateAttn(...)，保证 t=0 时前向逐位等于 vanilla TRELLIS。这条机制有六条强证据支撑：rectified flow 兼容（仍是一个速度场参数化，CFM loss 直通）、严格 identity-at-init（ControlNet 标准属性）、梯度无偏低方差（标准 backprop，无 SE(3) 在稀疏体素上的不可微 warp）、范式正确（IP-Adapter / AnimateDiff 直系）、多视图/多状态历史共识（MVDream/CAT3D/SyncDreamer 全是这套）、与已有 K-state shared-noise sampling 基础设施天然兼容。

**渲染与监督路径**：每个迭代步从 SS-DiT 解码到 SLAT，从 SLAT 解码到 3DGS（训练期）或 mesh（导出期）；按 K 个 θ_k 解析 SE(3) 变换 W(θ_k) 作用在显式 movable part 表示上（**这是用户明确接受的少量硬合成 + noisy-OR**，仅监督用，最终输出仍为单一 canonical base + canonical movable）；K-state 渲染拼成视频喂入 frozen Wan2.2，取 RFSDS 梯度。

**输出形式**：canonical base mesh、canonical movable part mesh、(type, a, p, range)、{θ_k}、最终 URDF。完全匹配用户硬约束 1。

## 4. Loss 项最终清单与各工作真实 loss 配置对比表

下表汇总 13 份工作在 GitHub 代码（或论文详尽描述）中实际计算的 loss 项数，是 RASA loss 削减的实证基准。

| 工作 | active default loss 数 | SDS 变体 | 关键正则 | 关节相关 loss | 阶段化？ |
|---|---|---|---|---|---|
| FreeArt3D | **2** | 3D-SDS (TRELLIS RF) | voxel-L2 | 关节通过 SDS 梯度，无独立 loss | 否 |
| DreamArt | 每阶段 ~1（共 3 阶段） | 无（视频扩散训练 loss） | – | rendering loss vs 合成视频 | 是 |
| CHORD | ~3 | W-RFSDS（rectified flow） | spatial + temporal smoothness | – | 否 |
| Paris | **4–5**（含 motion-type 阶段时） | 无（纯重建） | mask BCE、opacity entropy、part blender | composition/transform | 是 |
| ART | ~6–8（feed-forward） | 无 | part-set matching | axis、pivot、type-CE、limit | 否 |
| PAct | ~3–4 | 无（TRELLIS 微调） | KL、recon | 隐式（解码头） | 是 |
| ProlificDreamer | **3 active default**（VSD+entropy+orient）；7 命名 lambda 跨阶段 | VSD | entropy、orient、opacity、tv、normal、lap | – | 是（3 阶段） |
| LucidDreamer | **3**（ISM+tv+scale） | ISM | tv、Gaussian scale、bin（默认关） | – | 否 |
| DreamGaussian | stage1 **3**（rgb_ref+mask_ref+SDS）；stage2 ~1–2 | SDS / Zero123 / MVDream | 无额外 | – | 是 |
| Magic3D | coarse **~4**（sds+orient+sparsity+opaque）；refine ~3 | SDS | orient、sparsity、opaque、+normal/lap | – | 是 |
| Fantasia3D | 每阶段 **1–2**（仅 SDS） | SDS | 无人工正则 | – | 是 |
| DreamFusion | **3** default（SDS+entropy+orient） | SDS | entropy、orient、opacity、tv | – | 否 |
| threestudio default | **7–8** 命名非零 | SDS/VSD/ISM 插件 | rgb、mask、normal_smooth、orient、sparsity、opaque | – | 按方法配置 |

**统计**：13 份样本中位数 = 3，均值 ≈ 3.5；纯 SDS 类生成工作的中位数 = 3；threestudio 默认 = 7–8；feed-forward 关节方法（ART、PAct）= 6–8。**结论：7+ 项不算异常但偏多，5 项以下属于"低于中位数"且仍能 AAAI 接收。**

**RASA 最终 loss 清单（4 项核心 + 2 项 stage-gated）**：

第一项 **L_W-RFSDS**（核心监督）：跨 K 个状态渲染的视频喂入 Wan2.2，取 v̂(z_τ;τ,y) − ε + z 形式的 RFSDS 梯度，τ 用 CHORD 的 high-noise-biased CDF 重要性采样（h(τ_i)=1−i/(I+1)），在两阶段架构中 SS 阶段把 τ 偏向高噪声路由到 high-noise expert，SLAT 阶段偏向低噪声 expert。**推荐权重 1.0（基准）**。

第二项 **L_rest_anchor**（必需锚点）：闭态输入图像与 K=0 状态渲染之间的 RGB-MSE + mask-BCE，10000·MSE_rgb + 1000·MSE_mask 直接照搬 DreamGaussian 的强权重，避免几何漂移与漂浮物。**推荐权重 1e4 / 1e3，warm-up 阶段独占。**

第三项 **L_part_entropy**（必需锚点，PARIS 风格）：H(P_movable(r)) = P·log(P)+(1−P)·log(1−P)，把 base/movable 软分配往二值化拉，破解分割-关节循环。**推荐权重 1e-3，全程开启。**

第四项 **L_disk_scale**（必需锚点，FreeArt3D 风格）：固定参考圆盘在所有 K 个状态下尺度一致的约束，防止 TRELLIS 单位立方体归一化导致的跨态尺度漂移。**推荐权重 1e-2，全程开启。**

第五项（stage-gated）**L_axis_prior**：当类别先验 / Particulate 预测器给出强先验轴 a₀ 时，在前 N₁ 步加 −cos(a, a₀) 的软约束。**权重 1e-2，仅 [N₀, N₀+1500] 步活跃。**

第六项（stage-gated）**L_θ_spread**：−Var({θ_k}) 防止 K-state collapse 到同一姿态，仅在检测到 Var 缩小时激活。**权重 1e-3，按需启用。**

被剪掉的项：normal_smooth / 3d_normal_smooth（TRELLIS 解码已隐含光滑先验）、orient（用 Option B 时跨态注意力天然提供 view 一致性）、sparsity（3DGS densify/prune 自带）、opaque（被 L_part_entropy 兼并）、cross-state photo consistency（被 L_W-RFSDS 兼并）、cross-state SE(3) cycle（by-construction，参数化已保证）、跨态 mask 一致（by-construction，硬合成保证）、texture VSD（合并到 SLAT 阶段的 W-RFSDS 中）、loss_claude 的 token-level cross-attn 一致性 loss（由架构保证）。

任何瞬时 active loss ≤ 4，远低于 threestudio 默认；这是一个 reviewer 友好的"克制"配置。

## 5. 一条线 vs 两阶段最终判定

**严格论证如下，最终推荐两阶段+τ-routing 单外循环。**

**支持纯一条线的证据**：HiFA 通过 timestep annealing 在单循环 NeRF 上工作；LucidDreamer/GaussianDreamer 在 3DGS 上单循环成功；Wan2.2 MoE 的 SNR-gated 高/低噪声专家分工 [verified from Wan model card] 提供了"几何/纹理"在 τ 维度的天然解耦先验，与 eDiff-I、SDEdit、Sander Dieleman 的"高 σ↔低频↔结构、低 σ↔高频↔纹理"论述一致 [hypothesis with strong indirect evidence]。

**反对纯一条线的证据**：ProlificDreamer 显式三阶段（NeRF→DMTet 几何→DMTet 纹理），README 直言"高质量 NeRF 是 stage 2/3 的前提"；DreamGaussian stage 2 默认 train_geo=False 冻结几何，论文明说"latent SDS 在 UV 上导致饱和块状伪影"；Magic3D coarse→refine 是硬阶段断点；Fantasia3D 在论文 FAQ 直接批评 DreamFusion/Magic3D"几何与外观耦合不利于精细几何"；TextMesh 因相同的过饱和问题而做 mesh-conditioned 重纹理。**已发表 SOTA 中改变表示拓扑的方法没有一个真正"单循环联合"成功**——HiFA 是唯一例外，但只在同质 NeRF 上工作，不涉及 SS↔SLAT 切换，且依赖一组专门设计的 annealing + 平滑机制。

**RASA 的特殊性放大了一条线的风险**：(a) 关节几何梯度本就微弱（一个 axis、一个 origin、若干 θ_k 的标量），极易被纹理 SDS 梯度淹没（stable-dreamfusion issue #315 报告了 DMTet 几何在纹理压力下停滞这一具体失败）；(b) TRELLIS 的 SS↔SLAT 在概念上就是"几何先于纹理"的两阶段表示，把它强行做成一条线不符合该模型的归纳偏置；(c) RFSDS 在不同 τ 区段的信号质量差异巨大，CSD/NFSD 等论文已实证高 CFG / 中 τ 段的梯度噪声大，让所有 τ 同时驱动同一参数 ill-advised。

**最终方案**——这是用户"理想是一条线"与代码事实的最佳折衷——**两阶段+单外循环+τ-routing**：

外层是一个 for 循环、一份优化器、一份配置文件、一份日志，呈现给用户和读者的就是"一条线"。内部用一个全局 step 计数器把训练分为三段：[0, N₀=300] 闭态几何 warm-up，仅 L_rest_anchor + TRELLIS-prior SDS；[N₀, N₁=3000] **SS 几何为主阶段**，τ 重要性采样集中在 [0.5, 1.0]，由 Wan2.2 high-noise expert 处理，激活 L_W-RFSDS + L_part_entropy + L_disk_scale + L_axis_prior，axis/pivot 梯度延迟到 N₀+200 才打开；[N₁, N₂=4500] **SLAT 纹理为主阶段**，τ 重要性采样转向 [0.0, 0.5]，由 low-noise expert 处理，几何参数（含 axis/pivot/θ_k/几何 Gaussian 位置）冻结或学习率降到 0.1×，纹理 SH/SLAT residual 全速学习。可选 [N₂, end] 极短联合 polish，τ 全段 annealing。

这套设计满足三个目标：**外形上单循环**（用户偏好达成）、**内涵上两阶段**（与 RF/TRELLIS/SDS 文献的成功路径一致）、**Wan2.2 MoE 自然适配**（τ-routing 直接利用 SNR 门控的专家分工）。在 AAAI 论文中可以诚实表述为"single-loop optimization with τ-stratified expert routing"，把它作为一个明确的方法学贡献而不是回避。

## 6. RFSDS gradient sanity test 协议

RASA 的 sanity test 是 AAAI 论文的一个独立卖点：CHORD 没有量化梯度方向 sanity，FreeArt3D 仅做任务级评估，**RASA 是首个对"frozen video model 的 RFSDS 梯度是否真的指向正确关节方向"做定量验证的工作**——这本身值得占主文一节。

**类别选择**：基于 PartNet-Mobility 八类——**单轴 revolute 干净类**：laptop、microwave、oven、refrigerator、dishwasher、eyeglasses；**单轴 prismatic 干净类**：drawer (StorageFurniture)、trashcan-slide；**类型混淆类**：scissors、faucet（用于 type-swap 测试）。每类 5 个实例 × 5 个噪声种子 = 200 sanity 样本。

**扰动设计**：连续型——axis 旋转 15°/30°/60°/90°、pivot 平移 0.05/0.1/0.2（物体归一化）；离散型——joint type swap (revolute↔prismatic)、GT mask vs 反转 mask（base/movable 互换）、partial mask（保留 50%）、θ_k 全零（静止）vs varying θ_k、刚体 vs 加 σ=0.02 高斯非刚噪声。

**度量**：连续扰动用 cos(−∇L, ϕ_gt − ϕ_perturbed) 与 ‖∇L‖ 单调性；离散扰动用 L(wrong) > L(GT) 通过率。

**τ 分层**：每个测试在三个 τ 桶——high [0.7, 1.0]、mid [0.4, 0.7]、low [0.0, 0.4]——分别运行，对每 τ 桶用 16 个 ε 样本平均以降方差。**关键 [hypothesis]**：axis/pivot/type/mask 这些结构扰动的 cos-sim 应在 high-τ 桶最大，texture-only 扰动应在 low-τ 桶最大；如果实验结果支持这个预测，就直接证明了 §3 中 τ-routing 设计的合理性，**这是 RASA 的另一个独立贡献**。

**通过/失败阈值**：PASS 需 ≥75% 的（类别 × 扰动）格子在 high-τ 桶满足 cos-sim 阈值（15° 扰动 cos > 0.3，30°+ cos > 0.5，0.1 pivot cos > 0.4），离散测试通过率达到上述细则；MARGINAL 60–75%，需要补救（加学习型 adapter 中介）；FAIL <60%，需要换 backbone。

**失败退路**：第一档救援——加强文本提示（"the laptop lid rotates open"），CHORD 实证 prompt 强度显著影响 motion fidelity；第二档——只走 high-noise expert 跳过 low-noise（lightx2v 已发布单专家 distill 版可参考）；第三档换模型——优先 **Wan2.2-S2V**（subject-to-video，对象条件更强），其次 **CogVideoX-5B**（更小但可承载完整 RFSDS 反传），SVD 因训练数据偏自然相机运动对物体关节运动较差，Open-Sora 短时序限制大。CHORD 的实测对比给出 Wan2.2 > TrajectoryCrafter > MotionDreamer > AnimateAnyMesh 的排序（用户偏好 87% vs 9.6%）。

## 7. 训练初始化与避免鸡生蛋蛋生鸡协议

循环依赖的破解依靠 **强先验初始化 + 时间相位序贯** 双管齐下，FreeArt3D（GIM 对应+pre-module）与 DreamArt（三阶段强排序）已实证有效。RASA 的协议如下。

**t=0 结构初始化（在主循环开始前完成）**：第一步对输入图 I₀ 做 TRELLIS 完整前向得到闭态 textured mesh 与 SLAT。第二步用 SAM-2 分割图像中 movable part 的 2D mask，借助 TRELLIS 的稀疏体素结构反投影到 3D，得到每个体素/Gaussian 的 base/movable 软分配（这是 part assignment soft mask 的 init）。第三步通过 VLM（或预编码的类别表）从图像分类得到对象类别，查类别表得到 tentative joint type 与初始轴方向（柜门→垂直 revolute、抽屉→沿前向 prismatic、笔记本→水平 revolute）。**第四步同时跑一个学习型 articulation predictor**——首选 Particulate (arXiv:2512.11798)，输入是 TRELLIS 已生成的 mesh，输出 axis/pivot/type/limit 与置信度；置信度高时用 Particulate 输出覆盖类别先验，否则保留类别先验作 fallback。**绝不允许随机初始化关节参数**，FreeArt3D Table-row-(d) 已实证随机 init 在该问题上失败。

**warm-up 阶段 [0, N₀=300]**：仅 L_rest_anchor + 闭态 TRELLIS-prior SDS 活跃；W-RFSDS、axis/pivot 梯度、θ_k 梯度全部关闭。目标是让 rest-state 几何收敛到 ~80%，使后续跨态 warp 操作在有意义的几何上发生。**门控判据**：Chamfer < 0.025（FreeArt3D 阈值），如果 N₀ 步未达，延长 warm-up，绝不带病进入下一阶段。

**SS 几何主阶段 [N₀, N₁=3000]**：激活 W-RFSDS（τ 偏高）、L_part_entropy、L_disk_scale、L_axis_prior、θ_k 梯度；但 axis/pivot 梯度再延迟 200 步到 N₀+200 才打开（避免在 mid-quality state estimates 下做 axis 更新引发翻转）；axis 梯度激活后用 0.1× 的 LR，每步后强制归一化 ‖a‖=1。

**SLAT 纹理主阶段 [N₁, N₂=4500]**：几何冻结或 0.1× LR，纹理参数全速。

**失败模式实时检测**：axis 翻转用 a·a_init < 0 持续判定，恢复策略是从类别先验重新 seed；base/movable 互换用 movable 质心位置突变检测，恢复策略是 freeze assignment 100 步并加大 L_part_entropy 权重；K-state collapse 用 Var({θ_k}) 缩小判定，恢复策略是激活 L_θ_spread；几何崩塌用 mean occupancy 监控；轴漂到物体内部（PARIS Fig. 8 失败模式）通过把当前 axis 投影到每个视图、检查是否穿过 movable mask 边界来判定。

**三大 novelty**：(1) **输入设定**——单闭态图 → 关节参数 + per-state θ_k + canonical base/movable mesh，无需关节训练数据，无需检索；与 DreamArt/SINGAPO/PAct 的差异在于不微调任何模型，与 FreeArt3D 差异在于只需单态。(2) **监督信号**——首次把视频扩散先验（Wan2.2 RFSDS）与 3D 原生先验（TRELLIS SLAT）通过一个可学习 adapter 在 SS-DiT 内部组合起来，称为 **bi-prior distillation**；CHORD 用 W-RFSDS 但不是 3D 原生 latent，FreeArt3D 用 TRELLIS-SDS 但无视频先验，**只有 RASA 同时具备**。(3) **架构**——learnable adapter inside frozen SS-DiT，是 ControlNet/IP-Adapter 范式在关节 3D 生成上的首次应用；PAct/ArtiLatent 微调骨干、FreeArt3D 完全冻结无 adapter，**RASA 的"轻量适配 + 完全冻结骨干"是中间路径，部署友好**。

**审稿人三大质疑与应答**：

**Q1"为何不像 PAct 那样微调 TRELLIS"**：(a) 微调需要高质量大规模带部件标签的关节 3D 数据，PartNet-Mobility 仅 2,346 实例 46 类且分布严重长尾，微调会耗尽先验、跨类别泛化差；(b) RASA 的 adapter ~100× 小于完整微调权重，可在任何 TRELLIS 升级上直接使用（TRELLIS.2 已发布）；(c) FreeArt3D 在论文中实证"Trellis-Enhanced SINGAPO"（即 PAct 思路）在关节指标上劣于 frozen-TRELLIS-SDS。

**Q2"单图几何模糊"**：(a) 承认是事实，正因如此用生成先验；TRELLIS SS-DiT 在图像条件下采样一个分布，RFSDS 在该分布中**选择**让 articulation sweep 在 Wan2.2 下最合理的模式；(b) 单图关节重建是已被领域接受的设定（DreamArt/SINGAPO/PAct/Articulate-Anything 都是单图）；(c) 提供不确定性消融——从 SS-DiT 采 N 个种子，报告 axis/pivot 方差，证明 RFSDS 把方差降低 ≥3×；(d) 失败优雅：图像真模糊时返回与图像一致的合理关节，是认知不确定下的正确行为。

**Q3"Wan2.2 没在关节数据上训练，RFSDS 真的有用？"**：(a) Wan2.2 比 2.1 多 83.2% 视频，包含日常关节物体（笔记本、柜子、烤箱）开合 [verified Wan model card]，high-noise expert 显式编码"overall layout"——这正是关节结构所在；(b) CHORD 已实证 W-RFSDS on Wan2.2 能产生语义忠实的关节运动；(c) **§6 的 sanity test 协议正是定量回答此问题**，写在主文将主动消解此质疑；(d) DreamArt 同样使用视频扩散先验，确认领域共识。

**AAAI 接收概率估计**：**35–50%（borderline-accept）**。强项是单闭态生成式管线、理论上可证的 bi-prior 组合、罕见的梯度方向 sanity 验证、frozen 部署友好。风险在于赛道拥挤——DreamArt/SINGAPO/PAct/FreeArt3D/ART/ArtiLatent 都在过去 18 个月内出现，许多来自 Microsoft/Stanford/UCSD/清华等强组，reviewer 容易给"incremental"。PAct (2026.02) 与 ART (2025.12) 是直接同期对手，需要小心处理 concurrent-work 状态。W-RFSDS 本身是 CHORD (2026.01) 的，不是 RASA 的——RASA 的贡献是**应用 + adapter + sanity test**。要把概率推到 60%+，需要：≥1 个类别 OOD 泛化案例（在不常见的 stapler/knife/faucet 上成功）、real-world 手机照片定性、把 sanity test 写进主文而非附录。

**实验设计**：主数据集 PartNet-Mobility 八类（cabinet/drawer/laptop/microwave/oven/refrigerator/scissors/eyeglasses）× 25 实例 × 4 articulation states；OOD 五类（faucet/stapler/knife/foldable-chair/dishwasher）；Real-world 20 张手机照片覆盖 5 类。Baselines：PARIS（多视图双态作上界）、DreamArt、SINGAPO、FreeArt3D、Articulate-Anything、PAct（concurrent，并列报告）、TRELLIS+启发式后处理（naive 消融）。Ablations 八项——无 RFSDS、无 SS-DiT adapter、无 high-τ 重要性采样、单专家 only、无 ε−z+v̂ 修正项、用 SVD 替代 Wan2.2、随机 init vs 启发 init、disk-norm 开/关。Metrics：Chamfer (整体+per-part)、F-Score@0.05、axis-angle 误差、pivot-distance 误差、part-segmentation IoU、joint-type 准确率、success-rate（全条件达成）、运行时间、real-image user study。预算约 5,000 H100·h。

## 9. 失败模式与预案（穷尽列出）

**架构层失败**：(F1) Option A velocity correction 导致 t=0 前向 ≠ vanilla TRELLIS，loss spike，先验扰动——预案是切回 Option B（本方案默认）。(F2) Cross-state attention 在 K=4-8 时计算/显存爆炸——预案是采用 sparse 或 windowed cross-attn，或借鉴 Native-3D-Editing 的 token concatenation + full attention 变体。(F3) Adapter 梯度被冻结骨干的大梯度淹没——预案是 ControlNeXt 的 distributional-matching normalization，或仅在每隔 N 个 block 注入一次。

**优化层失败**：(F4) axis 翻转 180°（PARIS Fig. 8 已记录）——检测 a·a_init < 0，预案是回退到类别先验，axis-LR 减半，加 gauge fix。(F5) base/movable 互换——用 PARIS 的 entropy 正则避免，检测靠 movable 质心突变，预案是冻结 assignment + 加大 L_part_entropy。(F6) K-state collapse 到同一姿态（典型当 RFSDS 信号弱时退化）——检测 Var(θ_k) 缩小，预案激活 L_θ_spread + 验证 Wan2.2 视频确实有运动。(F7) 几何坍缩到空/全占据——监控 mean occupancy，预案 disk anchor + per-state mask BCE。(F8) 轴落到物体内部（与 photometric 一致但物理错误）——投影到每视图检查是否穿过 mask 边界，预案加 ‖p − boundary_centroid‖² 软先验 200 步。(F9) 纹理过早收敛吃掉几何梯度（stable-dreamfusion #315 已记录）——这是用户最担心的一条线失败模式，预案就是 §5 的两阶段 τ-routing 本身。(F10) SDS 过饱和（DreamGaussian/TextMesh 已记录）——预案是 SLAT 阶段把 latent-SDS 换成 SDEdit 风格的 image-space MSE（DreamGaussian stage2 做法）。

**监督层失败**：(F11) Wan2.2 RFSDS 梯度方向不可靠（sanity test FAIL）——三档救援见 §6。(F12) Wan2.2 幻觉关节（闭态柜子前面合成出抽屉）——靠 τ 桶间 gradient-norm 一致性阈值过滤。(F13) RFSDS 高方差——用 16-32 个 ε 样本平均，或 Stein control variates（SteinDreamer）。(F14) 渲染分辨率不足导致 video model 看不清运动——3DGS 训练期 480p+，必要时升 720p。

**初始化层失败**：(F15) Particulate 在 OOD 类别上预测错——加置信度阈值，置信低退到类别先验。(F16) SAM-2 分错 movable part（如把把手当门）——VLM 监督一遍 mask 语义，必要时人工 prompt SAM。(F17) 类别先验缺失（罕见类）——退到 Wan2.2 视频 + 光流 RANSAC（最不稳但作为兜底）。

**评估层失败**：(F18) Reviewer 认为 W-RFSDS 是 CHORD 的因此 RASA 不 novel——主文反复强调 bi-prior + adapter 是新组合，sanity test 是新方法学。(F19) PartNet-Mobility 渲染偏差被 reviewer 抓住——补 real-world 手机照片定性。(F20) 单图模糊性 reviewer 不接受——补 N-seed 不确定性消融定量证明 RFSDS 确实降方差。

## 10. Milestone 路线图（含"如果只有 1 周时间"优先级）

**如果只有 1 周时间**：第 1–2 天**完成 RFSDS sanity test 协议的最小可行版**（2 类 × 3 实例 × 3 扰动 × 3 τ 桶）。这是整个项目的 go/no-go 信号——如果 sanity test FAIL，整个 W-RFSDS 路线就要换 backbone，越早知道越好。第 3–4 天**实现 Option B cross-state attention adapter 的 zero-init 注入**到 SS-DiT 第一个 block，跑 vanilla TRELLIS 等价性 check（adapter 关闭时输出与 frozen TRELLIS 逐位相同）。第 5–6 天**跑单关节单类别（laptop）端到端最小 demo**，N₀=300, N₁=1500，仅 4 个核心 loss，验证管线是否能从单闭态图生成出至少一个合理的关节运动。第 7 天**写 sanity test + demo 结果的 internal report**，决定后续投入。

**完整路线图**：

第 1 周：sanity test 完整 200 样本 + Option B adapter 完整集成 + warm-up 协议跑通 laptop。第 2 周：扩展到 microwave/oven/drawer 三类，验证 PARIS-style entropy 与 disk anchor 的必要性，跑 3 项核心 ablation（无 W-RFSDS、无 entropy、无 disk）。第 3 周：实现 SS→SLAT 两阶段 + τ-routing，验证两阶段优于纯一条线（这是 AAAI 主表的关键 ablation）。第 4 周：扩展到全部 8 类 PartNet-Mobility，跑 baseline（PARIS 上界、DreamArt、SINGAPO、FreeArt3D 必须复现），收集主结果表数据。第 5 周：OOD 五类 + real-world 20 张手机照，做不确定性消融（N-seed RFSDS 降方差证明）。第 6 周：失败案例分析、最终 ablation 表（八项）、AAAI 论文初稿。第 7 周：rebuttal 准备（针对 §8 三大质疑预演实验数据）、补救实验、论文打磨。
